12 · Design Principles
🌑
Dark-first
Every surface is black or near-black. Colour is used sparingly — red for brand, white for text, gradients for hierarchy.
💎
Glassmorphism
Cards and rows use 7–8% white fill + backdrop-filter blur to layer content without heavy contrast. Never use solid opaque cards.
🔴
Red is a signal
#E50914 marks the key stat or CTA on every screen. Use it for exactly one element per screen — don't dilute it.
📐
Fixed 375px canvas
All absolute positions are pixel-perfect for a 375×812 phone frame. Horizontal: 16–20px side gutters. Vertical: 97px chrome header.
✨
Ambient glow
Each screen has 1–3 blurred radial glows (blur 30–80px, opacity 0.15–0.4) behind content to create depth without imagery.
🎞
One action per screen
Each screen communicates one stat and optionally one action (tap to advance). Never compete for attention across multiple CTAs.
